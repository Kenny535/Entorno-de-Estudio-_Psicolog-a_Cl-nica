# Libro Principal

*Si el facilitador proporciona un libro en PDF, conviértelo a Markdown y colócalo aquí.*

## Instrucciones

1. Convierte el PDF a Markdown usando pandoc:
   ```bash
   pandoc libro.pdf -o libro_principal.md
   ```
2. Reemplaza este archivo con el resultado.
3. La IA priorizará este libro para responder preguntas.
